# 染色加工单单一投入与上游修正

## 1. 业务规则

来源：用户 2026-09-12 对染色加工单的最新确认，取代此前染色多投入 SKU 的演示要求。

- SU-001：一张染色加工单只加工一种投入物料，只关联一个上游组织。
- SU-002：同一上游可分批送货、分次接收；多张来源单据不等于多个上游。各单数量、单位、状态和入口继续保留。
- SU-003：新来货关联及备料分配不得给染色单增加其他物料或其他上游。
- SU-004：修正未操作的旧演示来源关联；不覆盖已有送货、实收、分配及用料事实。
- SU-005：列表、查看、导出口径一致；详情开始下一批无需选择其他投入 SKU。
- SU-006：毛织多纱线、混合来源送货单、仓库原单多物料、染色交出单多加工单功能保持原有范围。

## 2. 场景与边界

正常：面料中央仓以两张调拨单向 DWO-001 发出同一种棉布，列表显示一次仓库资料，下列两笔来源单据；接收分别累计。

阻断：berys 的相同棉布可以作为未关联生产单的备料接收，但不能分配到已有面料中央仓来源的 DWO-001。其他 SKU 同样不能加入该单。

旧演示：RCV-SRC-003 错绑 DWO-001。仅在没有送货、实收时解除演示绑定，保留这张真实字段完整的演示来货作为备料。已操作历史不静默改写，继续可追溯。
