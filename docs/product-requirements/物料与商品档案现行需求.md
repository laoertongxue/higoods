# 物料与商品档案现行需求

## 范围、继承与历史

本文件是物料档案、基础配置及商品档案简化要求的现行入口，汇集用户已确认的同页建档、分类与加工方式、档案页签和技术引用删除口径。它不改变业务规则，不代替代码，也不把历史验收升级成当前验收。

继承顺序：耗材与配件 R1 → 同页建档修正 R2 → 物料分类与加工清理 → 档案页签简化 → 款式与规格技术引用删除。后续明确修改的条款覆盖前阶段同一事项，未被修改的身份、单位、成本、文件和上下游约束仍有效。

- 当前专业物料：面料、辅料、纱线。
- 当前简单物料：耗材、配件。
- 原子需求与版本审查：[耗材配件 R1 矩阵](../product-design/pcs-consumable-parts-simplification/需求追踪矩阵.md)、[R2 矩阵](../product-design/pcs-consumable-parts-simplification/需求追踪矩阵-R2.md)、[分类及档案调整历史审查汇编](../prototype-review-records/2026-10-12-pcs-archives-consolidated.md)。原状态和证据版本保持，不用文件合并代替验收。
- 更早的[物料监控与决策方案](../material-decision-product-v2.md)及其[未完成追踪矩阵](../2026-09-14-material-decision-matrix.md)仍是独立业务范围，不因本次整理关闭其未完成条目。

## 1. 分类与基础配置

|物料|编码|唯一允许的下级分类|
|---|---|---|
|面料|FA|SZ 梭织面料；ZZ 针织面料；LL 里料/衬布；MZ 毛织/羊毛面料；YH 印花/提花面料；GN 功能/特殊面料|
|辅料|TR|SN 缝纫/衬布类；BF 扣合类；LR 花边/蕾丝类；TB 织带/编带类；LB 标识类辅料；HD 五金；OT 其他类目|
|纱线|YR|NF 天然纤维纱线；CF 化学纤维纱线；BL 混纺纱线|
|耗材、配件|沿用各自主档编码规则|无下级分类，无属性模板|

专业三类的分类业务编码与身份使用同一当前配置，创建和导入不能增加表外分类。辅料选择 BF 扣合类，必须明确选择机打或手缝，没有默认值；保存、编辑、审核和导入保持一致。该类型与孔式、脚式结构分开。旧档未登记时显示待补，编辑时补齐，不猜填历史事实。

耗材、配件的基础配置只配合单位、包装和编码规则。固定单位换算维护相同物理量之间的统一比例；跨量纲换算、每包含量及包装成本由具体规格维护。不得把某种物料的每卷长度或每包件数写成全局固定比例。

专业分类属性直接维护当前资料，取消模板版本管理、版本换算依据与使用情况。旧分类仅按明确映射读取，不维持两套可写分类。配置整理不能清空用户存储、破坏历史身份、金额与单位快照。

## 2. 耗材、配件同页建档与编码

一个主档对应多个规格；同一种物料的不同型号、尺寸或颜色使用独立规格编码。一个编辑页同时填写主档资料和多行规格，一次保存；至少一行，最多 100 行。新增、复制和移除仅作用于未保存行，不能通过删行删除既有规格及历史业务。

保存前按行校验型号、主单位、规格重复及金额，错误明确行号并保留输入。已有规格保留 ID、编码和关联；审核后型号与主单位锁定。编码使用已配置规则及主档前缀、B 序号，历史编码不重建。历史加工规格在完整主档编辑中只读保留，费用、版本、附件和同名不同阶段不改；允许追加普通基础规格。

主档、多个规格、成本、图片引用和操作记录由现有 PCS 同库事务一次保存，事务完成后才显示成功。准备失败、事务中止、重复点击和多标签冲突不能产生半套数据。静态演示直接读，用户文件保存原始 Blob 与文件引用，未保存输入只在内存。

规格成本按其主单位维护；已有非主单位报价通过原规格成本入口维护，完整主档编辑不改变既有采用关系。图片、补充说明按需展开，单位与包装复用现有规格维护入口。

导入导出取消耗材、配件分类编码。旧列模板须重新下载，拒绝错误列位。采购按物料类型和规格选择；BOM 行用途明确选包装材料或其他，不能根据名称猜测用途。耗材支持这两种用途，配件禁止新入服装 BOM；既有采购和 BOM 历史快照保留。

## 3. 列表、审核与操作

耗材与配件列表每个 SPU 一行，规格 SKU 列展示全部所属规格及识别信息、单位和费用。筛选、统计、分页、勾选和批量审核均按主档，确认审核时列出实际处理规格。主档通过后新增草稿规格，仍可按本档提交；可选条件按审核状态判断。

取消启停、归档、已保存规格复制、使用情况和更多操作弹窗。有效操作直接展示在操作栏并可换行。未保存编辑行的复制便利保留。标题放左侧，已选择项数、提交审核、审核通过、列设置及批量结果入口紧凑排列在右侧。

## 4. 加工定义与费用

染色明确选 MJS 或 GTG，分别保留产出编码、加工定义及本道含税加工费。印花四种互斥方式：单面印 A、渗透印 CT、双面同花 AA、双面分花 AB；AB 明确两面花型及其版本，不自动代填。各方式允许独立费用。

综合成本沿用基础采购、基础运输及每道含税加工费，普通单位和包装换算保留。加工定义、产出规格、费用及其采购/BOM/工厂引用属于有效基础事实；基础档案不承担执行计划反查和创建。

## 5. 档案页签、附件与引用

面料、辅料、纱线主档及规格删除技术引用和复制主档；规格删除加工计划页签、创建计划、专用反查、跳转及专属代码。工厂模块自身计划、BOM、采购、加工定义及历史单据保留。

专业主档和规格取消独立资料页签。主档基本资料维护通用识别图片和规格说明；规格页签维护该规格图片与说明；加工关系展示当前工艺色样、投入/花型说明及执行文件。

基础资料只提供识别图片/规格说明；染色只提供确认色样/染色标准；印花、绣花、烫画按对应工艺提供执行文件。文件名可作为资料名称，历史资料版本收起。既有八种用途资料按原归属仍可读，不删除文件字节或关联。执行稿修订保留旧引用；保存失败保留文件和输入，切换未保存内容有提醒，不把文件保存到其他主档或规格。

款式档案和规格档案也删除技术引用页签、技术包/核价引用区域及专属查询、跳转和事件。技术包、核价本身的模块与业务数据，以及真实关联、审核、身份和生命周期防错保留。

## 6. 验收边界

正常场景：耗材或配件一次创建两个规格，保存后增加第三个，按主档审核并刷新回读；专业分类、BF 类型与加工方式在保存和上下游读取一致。

边界场景：空型号、重复规格、非法金额、已审核身份修改、旧分类导入、AB 缺少一面花型、附件归属错误、取消及事务失败均按对应规则处理；删除的页签不能经旧事件重新打开。

原子矩阵、两轮逐项审查及真实页面/存储/性能证据按原验证版本追踪。换片布、物料决策等范围中的实物接受或未完成条目不能因本文件整理改为通过。新增需求或实现变化再按 AGENTS.md 执行适用验收。
