# Group 3 入库管理 — 测试环境实点汇总 (2026-10-14)

## 预入库管理 `/wls/inbound_manage/index`
- 筛选：全部仓库（A&C WH / F&M WH）、全部类型（采购入库/工厂回货/调拨入库/手动入库/kol预留）、搜索/清除、创建入库单
- 状态 Tab：全部(4)、待收货(3)、部分收货(0)、收货完成(1)、部分上架(0)、上架完成(0)、异常(0)
- 表列：单号（入库单号+关联单号+生产单）、商品SPU、商品SKU（含 X 数量明细）、入库仓库、入库类型、操作人（创建/收货）、送货单位、送货数量、已收数量、货主、状态、时间（创建/更新）、操作
- 行操作：查看详情、更换仓库、开始收货（待收货时）；收货完成后仅查看详情
- 送货数量 440 / 已收 0 → 待收货；已收=送货 → 收货完成

## 入库单列表 `/wls/inbound_manage/receive_list`
- 状态 Tab：待上架(1)、部分上架(0)、上架完成(0)、异常(0)、搜索/清除
- 表列：单号、入库仓库、状态、收货数量、SPU编码、SKU编码、库区/库位、时间、操作
- 行操作：详情、上架（待上架时）

## 成衣换码任务 `/wls/change_product_task_manage/index`
- 页头说明：查看成衣 SKU 换码任务，可按任务单号、生产单号、SKU 查询；创建时按生产单或源 SKU 搜索成衣仓库存，在明细行填写替换 SKU
- 筛选：搜索/清除/创建任务单
- 状态 Tab：全部(0)、待处理(0)、部分完成(0)、已完成(0)
- 表列：单号信息、换码明细、任务状态、时间、操作
- 测试环境当前无数据

## 退货入库列表 `/wls/return_inbound_manage/index`
- 页头说明：处理退货上架。可售入现货，瑕疵入瑕疵库存，报废不入库存
- 筛选：全部仓库（F&M WH / A&C WH）、全部退货类型（未知/售后/拒收）、搜索/清除
- 状态 Tab：全部(0)、待上架(0)、部分上架(0)、上架完成(0)、异常(0)、未知(0)
- 表列：单号、SPU、SKU、上架数量、退货类型、时间、操作人员、状态、操作
- 测试环境当前无数据
