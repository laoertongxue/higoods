# Group 2 基础数据 — 测试环境实点汇总 (2026-10-14)

## 仓库管理 `/wls/warehouse_manage/index`
- 筛选：类型（全部/自建/合作）、属性（全部/成衣仓/面料仓/辅料仓/纱线仓/耗材仓/包材仓/中转仓）、搜索/清除/新增仓库
- 表列：仓库名称（含编码如 WH-FABRIC-006）、类型、所属主体、仓库属性、联系人、库区/库位总数、国家、时区、是否启用、操作
- 行操作：编辑、绑定账号、删除
- 15 行/页

## 库区库位管理 `/wls/zone_manage/index`
- 筛选：全部仓库（15+ 仓库下拉）、全部类型（拣货/存储/打包/退货/kol/暂存）、搜索/清除
- 主操作：添加库区、添加库位、库位导出、打印库位标签
- 表列：勾选、ID、库区名称、所属仓库、库位总数、库区类型、是否启用、操作
- 行操作：查看库位、编辑类型、编辑、删除

## 仓库主体管理 `/wls/subject_manage/index`
- 无筛选字段（仅搜索/清除/新增主体）
- 表列：主体ID、主体名称、类型、税号、银行账号、联系人、电话、是否启用、操作
- 测试环境当前无数据

## 编码生成规则管理 `/wls/generate_code_rule_manage/index`
- 筛选：条码对象（全部/商品SKU/收货单/上架单/入库单/出库单/拣货单/成衣盘点单/成衣调拨单/原料盘点单/退货单/质检单/退件入库单/原料入库单/中转入库单）、状态（全部/启用/停用）、查询/重置/新增规则
- 表列：规则名称、条码对象、编码前缀、日期格式、流水位数、示例编码、状态、操作
- 测试环境当前无数据

## 集货标签管理 `/wls/collect_container_manage/index`
- 页头说明：维护集货标签编号，支持批量添加并打印条码标签
- 筛选：全部仓库（F&M WH / A&C WH）、全部状态（启用/停用）、搜索/清除
- 类型 Tab：全部(0)、拣货篮(0)、集货篮(0)
- 主操作：批量添加、批量打印标签、启用、停用
- 表列：勾选、编号、类型、仓库、状态、最后打印时间、创建时间、操作
- 测试环境当前无数据
