## 业务规则与计划
1. BAR：产出条码独立维护，零数量可保存草稿但不得建交出单；码号唯一、缸号可追溯，单位沿用原单，yard/meter换算不用于kg/pcs。编辑不改包装完工事实。复用实际Code128。
2. DOC：按实际产出卷建草稿、合入草稿；卷不得重复占用；允许多加工单但必须同加工厂，按接收方及单位分别显示数量。确认交出使用已有交出事实，不产生接收事实。删除、作废、交出二次确认。
3. PRINT：产出标签与SURAT JALAN打印预览，保留数量单位、原单和接收方，草稿打印明确标识；流程卡沿用现有实现。
4. KEEP：原列表结构保留；当前水溶和仓库来源事实保持，新增能力不制造库存。正式物料图片缺失明确展示，不借图冒充。

工作包：A 在 dyeing-task-domain.ts 现有事务中增加条码和单据；B 在 output-documents.ts 增加局部弹窗，work-orders.ts 增加入口；C 专项命令、页面、打印和低分辨率验收。既有流程卡、编辑、日志不重写。
