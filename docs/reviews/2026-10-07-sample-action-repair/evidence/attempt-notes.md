# 失败尝试与最终证据区分

保留 attempt-01～04、boundary-attempts 及 early-failure-images，不作为最终通过证据。早期测试曾因 Vite HMR 导入产生双运行实例、抽屉关闭命中了遮罩、分页测试选择了第二页对象、共享故障提示重复匹配而失败；之后修正服务/定位器，并发现申请列表缺失重置按钮，已修复后全量重放。

attempt-01 的旧 pass 字段只反映当时已测耗时，无完整流程含义；最终 browser-1～5.json 的 pass 必须同时满足完整流程结束、无未捕获错误及每条耗时 <=1000ms。

边界调试先误把页面级读取失败提示当成列表内提示，然后重新读取触发整页 reload，使仅存在页面内存的计时起点丢失。最终使用测试专用临时 sessionStorage 记录事件绝对时刻，跨 reload 仍从点击开始计时；只保存测试时间戳，不保存业务数据。保留失败日志及原始记录，NaN 不视为通过。

最终验证原始记录为 browser-1～5.json、boundaries-1～5.json，以及同目录的本轮回归结果；测试脚本、环境与版本归属见 verification.md。未剔除任何有效最终测量的慢样本。

最终补查：编辑页已选样衣时，读取失败后的表单重绘调用失效缓存，导致落到全页读取错误。改为原 DOM 提示并保留字段和已选图片，读取依赖控件禁用，重试/取消仍可用；新故障契约包含已选样衣、保留输入、失败后继续填写及明确确认后的重试。最终 diff 同时发现库存重置入口重复，删除多余入口，并新增七页重置数量恰为一项断言。随后对冻结的源文件重新运行全部页面/全流程/标签回归。
