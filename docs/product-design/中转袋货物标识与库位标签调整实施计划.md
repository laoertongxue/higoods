# 中转袋货物标识与库位标签调整实施计划

实施基线：`codex/process-craft-techpack-sequence@d5ccec7d`
任务边界：库位标签、袋身份标签纸张、货物标识及“菲票装袋／中转袋入仓”打印入口
执行状态：WP-01～WP-07 已完成；完成证据以需求追踪矩阵和原型审查记录为准，本计划不替代验证证明。

## 1. 目标与完成标准

按总体设计完成三个标签对象和两处列表的完整闭环。完成不是“页面上出现按钮”，而是每条原子需求都有当前代码实现、自动化契约、命名页面／打印证据和最终状态；最后一次实质修改后重新生成证据。

## 2. 工作包

### WP-01：库位标签 100×100 五段式重排

- 业务目标：第三层货架下方仍能看清库位并尽可能扫到二维码或条码。
- 文件／符号：`src/pages/process-factory/cutting/warehouse-location-map.ts` 的库位标签预览和打印样式；既有真实条码、库位标签事实源保持复用。
- 修改：纸张改为 100mm × 100mm；按完整库位、库区仓名、层位指示、放大二维码、放大条码排列；保留单库位及货架／库区／仓库批量范围。
- 编号规则：货架、层和层内位置使用有限正整数，不设置固定业务上限；编号至少补足为两位，超过两位时完整保留。
- 验证证据：库位标签专项、真实库位图预览、打印 CSS 尺寸和批量张数断言。
- 完成条件：五段内容完整，二维码／条码无遮挡，100% 比例下一页一张。

### WP-02：中转袋身份标签纸张对齐

- 业务目标：匹配第二个 100mm × 100mm 标签口袋，同时不改变物理袋身份语义。
- 文件／符号：`src/pages/print/templates/label-print-template.ts` 的 `buildTransferBagLabelPrintDocument`。
- 修改：纸张类型从 `LABEL_100_60` 改为 `LABEL_100_100`；保留袋号、工厂、建立时间、二维码和条码。
- 验证证据：打印模板专项及身份标签预览。
- 完成条件：尺寸正确且票面没有款号、颜色、尺码或库位字段。

### WP-03：货物标识事实源与矩阵投影

- 业务目标：准确打印某个袋子某次使用周期实际装入的裁片。
- 文件／符号：`wait-handover-runtime.ts` 装袋快照按使用周期解析；新增货物标识矩阵数据模块；`transfer-bags-model.ts` 列表行补充周期和入仓真实性。
- 修改：支持按 `usageCycleId` 解析历史装袋事件；校验单生产单、有效菲票和正数片数；按颜色尺码聚合并生成 4×6／3×8 分页；计算页小计和整袋合计；按部位编码（缺失时按部位名称）计算去重部位数量，但不向打印票面输出具体部位信息。
- 验证证据：纯函数专项覆盖单页、多色多码、超版、历史周期、空快照和总量守恒。
- 完成条件：所有非零组合恰好进入一页，全部页总量等于装袋快照总量。

### WP-04：100×100 货物标识打印模板

- 业务目标：让现场不扫码也能辨认袋中货物，并按袋号插入正确口袋。
- 文件／符号：`print-service.ts` 打印类型；`print-template-registry.ts` 注册；`label-print-template.ts` 构建和矩阵渲染；`print-preview.ts` 来源识别；路由链接。
- 修改：新增独立货物标识文档类型和业务布局；黑白文本／表格渲染，不出现图片、二维码或装饰色；基础信息只显示“部位数量 N 个”，不得输出部位编码或名称；批量来源支持多个使用周期；每个矩阵页生成一张标签纸。
- 验证证据：打印文档专项、预览 DOM／CSS 和多页截图。
- 完成条件：单袋与多袋均一页一张，页码、袋号、矩阵和总计完整。

### WP-05：菲票装袋列表打印入口

- 业务目标：装袋完成后立即打印或批量打印对应货物标识。
- 文件／符号：`warehouse-hub.ts` 的菲票装袋表格、局部选择状态和事件处理。
- 修改：行操作新增打印；工具区新增批量模式、当前页全选、跨页保留、已选计数、打印已选和取消；目标使用周期作为打印来源。
- 验证证据：命名页面自动化覆盖单行、批量、翻页／当前页全选、无选择阻断。
- 完成条件：既有详情和继续入仓不回归，批量选择不串到入仓页签。

### WP-06：中转袋入仓列表打印入口与事实修正

- 业务目标：已入仓记录可补打同周期货物标识，且列表不伪造入仓事实。
- 文件／符号：`warehouse-hub.ts` 运行时行构造和入仓表格。
- 修改：区分装袋事件与真实入仓事件；入仓页只接收 `hasInboundRecord` 记录；增加同 WP-05 的行级／批量打印。
- 验证证据：专项和页面检查“未入仓袋不出现、已入仓袋可打印、周期一致”。
- 完成条件：页面入仓时间、人、库位均来自真实入仓事件。

### WP-07：追踪、治理与最终验收

- 业务目标：证明没有遗漏、混淆标签对象或破坏相邻打印能力。
- 文件／符号：三份产品文档、需求追踪矩阵、原型审查记录、专项测试。
- 修改：逐项补齐实际符号和证据；执行正向／反向追踪；记录热敏无图片例外。
- 验证证据：相关专项、列表治理、命名浏览器、100×100 打印预览、构建、CodeGraph 同步／状态和任务收据。
- 完成条件：矩阵无未说明的待实施、实施中、待验证或阻塞项；若外部条件确有阻塞，必须明确列出且不得宣称完整验证。

## 3. 依赖顺序

`WP-03 → WP-04 → WP-05/WP-06`；`WP-01` 与 `WP-02` 可独立实施，但统一进入 `WP-07`。页面和打印验收必须使用当前分支、当前工作树启动的同一服务。

## 4. 风险与控制

| 风险 | 控制 |
| --- | --- |
| 把库位标签误当袋身份标签 | 三种打印类型、构建器和验收编号分离；票面字段反向检查 |
| 同袋号后续复用导致补打错内容 | 打印链接只传 `usageCycleId`，按周期读取冻结快照 |
| 多颜色多尺码被压缩或截断 | 明确每页容量和自动续页；专项校验非零组合完整性 |
| 部位数量多或名称过长挤压矩阵 | 票面只输出去重部位数量；专项使用超长部位名并反向断言名称不进入 HTML |
| 矩阵合计与袋总数不一致 | 页小计、矩阵总计、快照总计三重守恒断言 |
| 入仓页展示未入仓袋 | 新增 `hasInboundRecord`，禁止用装袋事件回填入仓事实 |
| 批量跨页丢选择或串页签 | 两个页签独立选择集合；当前页全选和跨页保留专项 |
| 黑白热敏模板出现图片或低对比色 | 专用纯文本矩阵布局；预览检查无 `img` 和无彩色业务信息 |
| 修改共享打印模板影响菲票等标签 | 独立业务布局分支；现有身份标签和菲票打印相邻回归 |
