# C02 毛织独立中央 PDA：当前源码审查与实施范围

本文件继承完整PDA拆分的C02、X01～09及当前项目业务优先原则；不替代裁床剩余项或其他中央/三方模块。当前为实施阶段，未宣称已交付。继续使用现有PCS按记录仓库和毛织/工厂实收事实，不新增后台、鉴权、业务localStorage或独立库存。

## 当前已核对的来源和差异

- 当前Web的横机、缝盘两阶段使用wool-domain的WoolWorkOrder、commands、stage-facts/rules/queries；stage-orders/detail显示的按钮及门禁来自同一原域。毛织不是通用辅助工艺四按钮页面，只接当前横机和缝盘阶段，不新增其他毛织工序类别。
- 横机、缝盘加工填报的原单位是“件”，包括部位毛织对应成衣件数。外发具体部位片交出才按“片”，由pieceCountPerGarment派生可交片数，不能直接把一件改标一片。
- 无外加工时，横机填报自动生成内部交接、缝盘实收和适用缝盘填报；不得让员工重复接收/交出。不自动闭合外发工艺片，外发各节点及最终回货仍以真实收方确认事实为准。
- 接收读取factory-receiving的已交出/已审核有效来货。纱线由毛重和三种管型去皮至克，筒数必须等于三种数量之和（纸管62g、锥形80g、宝塔121g）；PDA可计算筒数，不另让员工重复填写。部位片按正整数片接收，不能填纱线称重字段。
- 绑定横机单的纱线按来源剩余净重校验；未绑定备料的现行Web没有相同的硬性来源净重上限，不能偷偷套用另一规则。备料仍需沿原分配动作关联正确横机单，不能因接收就伪造加工就绪。
- issueWoolYarn/returnWoolYarn按当前加工单、纱线SKU、精确批次和实际物位；领用不超当前库存，累计退回不超对应批累计领用。加工填报按原150%/实际回货上限；完单核对实际加工/交出/直接下游实收并释放适用横机关联。
- 毛织仓管需保留待加工纱线的领用、余纱退回，以及待交出部位片/成衣库存及收发记录，不能套用辅助工艺纯记录页。实际机器关联是横机执行动作，新增/维护机器档案不在员工页面另造入口。

## 数据边界

实际对象：WoolWorkOrder、纱线实收/备料分配、领用/退回、加工填报、外发片/成衣交出、内部自动衔接、外工艺片回货、完单与机器关联。原读写入口为wool-domain/store的只读查询及runWoolRecordCommand、factory-receiving-links；PCS codec将毛织集合拆为按身份记录，普通读取不落整包种子。接收只保存原工厂实收，再由projectFactoryReceiptsIntoWool投影库存/就绪，不另写一份实收。

当前CLI索引属于本隔离工作树；其版本没有explore/trace子命令，因此context/callers后直接读已定位源文件，不使用指向原4832的MCP结果冒充本版本。
