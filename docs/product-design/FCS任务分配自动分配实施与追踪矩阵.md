# FCS 任务分配自动分配实施与追踪矩阵

## 目标与完成标准

在统一任务分配页面补齐与线上口径一致的“自动分配配置”和“执行自动分配”。生产计划员先按工序工艺维护是否启用、默认承接工厂和任务截止天数，再预览当前可处理任务；经过独立的价格二次确认后，系统按任务或技术包标准价批量直接派单，并冻结工厂、价格、数量和截止日期。

完成标准是配置、预览、二次确认、执行结果和失败反馈均可在当前本地分支实际操作；车缝、合并任务、整单任务和生产准备加工单不得进入自动分配。

## 范围与非范围

- 范围：待分配、允许自动分配的非车缝独立生产任务。
- 分配方式：仅直接派单；不自动发起竞价，不自动暂不分配。
- 价格：读取任务或技术包标准价，执行前二次确认，提交后写入冻结派单记录。
- 时间：任务截止日期按分配日期后的自然日计算；工厂是否按时接单继续服从接单时效配置。
- 非范围：车缝任务、两类合并任务、整单任务、生产准备加工单、合同生成、PDA 操作、菲票装袋与裁床拆袋重装。

## 实施顺序

1. 建立自动分配候选边界和工序工艺配置。
2. 在统一任务分配页提供配置与执行入口。
3. 执行前重算候选任务，并显示纳入、排除和异常数量。
4. 经过价格二次确认后逐任务生成直接派单事实，保留成功和失败明细。
5. 运行专项契约、命名页面、构建、治理和正反向追踪。

## 验收场景

- 正常配置：启用一个非车缝工序，选择有效工厂并填写自然日，保存成功。
- 正常执行：预览显示候选任务及冻结价格，二次确认后任务进入已直接派单。
- 无配置：任务计入“未启用配置”，不被执行。
- 工厂失效：任务计入工厂异常，不被执行。
- 无标准价：任务计入价格异常，不被执行。
- 范围边界：车缝、车缝+烫包、裁剪+车缝+烫包、整单和准备加工单均不出现在执行明细中。
- 部分失败：其他有效任务继续执行，结果反馈列出失败明细。
