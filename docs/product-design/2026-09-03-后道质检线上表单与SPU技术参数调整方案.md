# 后道质检线上表单与 SPU 技术参数调整方案

> 日期：2026-09-03  
> 状态：当前执行口径；实现与验证状态以同名需求追踪矩阵为准  
> 依据：用户本次确认、线上质检表单截图、《QC后道全流程系统功能需求》及当前代码  
> 取代口径：取消“每次回货单独上传并冻结质检参考资料”，改为“按 SPU 统一维护技术参数，质检时按 SPU 引用”。

## 1. 目标和边界

在不改变“一次回货生成一张质检单、一张质检单只能由一名质检员执行”的前提下，把 Web 质检工作台调整为贴近线上操作的质检表单，并让质检员在同一视野对照 SPU 的颜色和尺寸技术参数。

本次范围包括 Web 质检单列表、Web 质检工作台、质检结果共享事实、SPU 技术参数 Mock 与持久化、待加工仓的关联入口以及相关测试。不把颜色对照图或尺寸标准写入技术包；不实现真实后端、生产文件存储、物理 PDA、扫码枪或打印机验收。

## 2. 质检表单业务口径

### 2.1 数量结构

每个 SKU 的质检结果由三类数量组成：合格数量、瑕疵数量、返工数量。

- 待质检数量由送检事实带入，质检员不修改。
- 合格数量由质检员填写。
- 返工数量由质检员填写。
- 瑕疵数量不手工填写，由各瑕疵原因的数量实时汇总。
- 守恒式为：`合格数量 + 瑕疵数量 + 返工数量 = 待质检数量`。不相等时按“回货后任何差异都需授权”处理。

### 2.2 瑕疵原因

表单按线上形式直接展开原因数量，使用以下 12 个固定项：做工原因、脏污、抽纱、做错、布料原因、缺辅料、做毁、印花、色差、半套、破洞、缺辅料不补。每项默认为 0，不允许负数；瑕疵汇总随原因数量立即更新。

不收集“瑕疵证据图片”、图片地址或责任方自由文本。已有历史数据字段可保留为不可见兼容信息，但不得在当前质检页继续要求填写。

### 2.3 返工工厂

- 返工数量为 0 时，“返工接收工厂”不参与业务，控件应隐藏或置灰，不能误导质检员必须选择。
- 返工数量大于 0 时，工厂必填；从工厂主数据中搜索选择，不允许提交不存在的自由文本。
- 返工原因在有返工数量时必填，用于说明返工事实。

## 3. 质检工作台布局

工作台在桌面宽屏上分为两栏：

- 左栏是主操作区，依次展示质检单与领取信息、结果汇总、各 SKU 质检表单、加工项目和完成操作。
- 右栏是“SPU 技术参数”对照区，在滚动质检表单时保持可见。展示 SPU 名称、图片、颜色对照图与说明、各尺码的胸围/衣长/肩宽/袖长及可选的尺码图。
- 技术参数未维护时明确显示“未维护”和维护入口，不用占位图冒充真实资料。
- 小屏下改为上下排列，不产生页面主体横向滚动。

## 4. SPU 技术参数维护

### 4.1 列表入口和标识

质检单列表右上角新增“新增 SPU 技术参数”。列表每个 SPU 明确显示“已维护”或“未维护”；状态是可操作入口。

- 从顶部入口打开：SPU 初始为空，必须使用支持关键词搜索的下拉列表选择。
- 从列表行打开：自动带入该质检单的 SPU，不允许用户再次选错。
- 选择后展示 SPU 编码、名称、图片和尺码列表，图片支持大图查看、关闭按钮、遮罩和 `Esc` 关闭。

### 4.2 维护内容

- 颜色对照图：可选本地文件或填写图片地址，可填补充说明。
- 各尺码尺寸：按 SPU 已有尺码展开，填写胸围、衣长、肩宽、袖长，或为对应尺码上传尺寸图。
- 一个 SPU 保留一份当前技术参数，同 SPU 的不同质检单共用；再次保存是更新，不重复新建。
- 当前原型中，“已维护”的最低判断是：存在颜色对照图，且每个尺码已填全四项尺寸或已提供该尺码尺寸图。

## 5. 上下游联动

- 质检单列表和质检工作台读取同一份 SPU 技术参数，保存后两处立即一致。
- 待加工仓不再维护“本次回货的质检参考资料”，只提供前往质检单统一维护的入口。
- 技术包仍不增加颜色对照图或尺寸标准，不把 SPU 技术参数误认为技术包内容。
- 质检提交仍使用现有质检单、领取人、加工项目、差异授权和下游后道加工单链路。

## 6. Mock 与验收口径

Mock 至少覆盖 3 个可搜索 SPU，包含“已维护”和“未维护”；尺码行与 3 个生产单×5 SKU×5 次回货的全流程 Mock 兼容。

本次完成判断必须包含：

1. 两遍业务需求与代码/页面反向核查。
2. 两轮 3 个生产单×5 SKU×5 次回货的 Web＋浏览器 PDA 全流程。
3. 质检单列表新增/行维护、SPU 搜索、图片、尺寸、状态及双栏工作台的命名 UI 证据。
4. 瑕疵自动汇总、返工数量和工厂的显隐/必填/主数据校验。
5. 构建、相关专项、列表和原型治理、CodeGraph 状态与任务收据。

浏览器中的 PDA 视口、文件选择和打印预览不等于实体设备、真实文件上传服务或生产上线验收。
