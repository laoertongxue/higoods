# PCS 测款单建单与商品档案信息优化

## 需求与范围（2026-09-23 用户确认）
新建测款单使用独立页面 `/pcs/testing/orders/create`，从商品档案选择 SPU 和 SKU，指定买手。商品属性只在商品档案维护；建单和测款详情直接读取当前商品档案，不复制属性、不提供填写属性的入口。列表新增买手列。移除列表内嵌的新款建档表单。保留已有测款步骤及同 SPU 至多一张进行中单的规则。旧单无买手显示待分配；旧档案无属性显示待完善，不编造业务事实。

## 实施计划
1. 商品属性 → 档案类型、属性展示与维护 → 补全字段，复用已有字段 → 属性读写及旧数据兼容契约。
2. 建单 → 独立页面、路由、处理器 → 选择档案和 SKU、指定买手，局部更新选款信息 → 空值、错误 SKU、重复 SPU、成功建单验证。
3. 列表与详情 → 买手、只读档案属性 → 查询统计一致、列设置与导出 → 命名页面与图片验收。
4. 交付 → 类型、专项、构建、治理、1366×768 与 1280×720 页面 → 记录原始性能样本；不沿用旧任务性能例外。
