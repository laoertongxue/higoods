# 毛织、辅助工艺、特种工艺 PDA 单一加工单事实实施计划

## 1. 目标与完成标准

将三类工艺 PDA 收口为一套加工单事实，按 `交接` 与 `执行` 分配动作，彻底删除仓管第二套写逻辑，并让确认接收、发起交出、加工填报优先扫描生产单 / 加工单。完成时不存在可绕过 Tab 白名单或从旧仓管页面写入加工事实的入口。

## 2. 事实依据与边界

- 产品确认：`交接`承载确认接收、发起交出；`执行`承载加工填报、完成加工单和毛织专属关联横机设备。
- Web 端现有加工单事实与领域动作是继续复用的权威事实源，本次不改变 Web 业务。
- 实施工作树：`codex/pda-knit-aux-special-scan-handover`，起点 `999bbb0f73724dd988607473a4dafc62b36fb0cf`。
- 不改裁床、后道、中央成衣仓等其他流程，不引入真实扫码 SDK 或后端基础设施。

## 3. 工作包

### WP-1：Tab 动作白名单与单一事实入口

- 业务目标：页面分工清楚，但保存统一落入原加工单事实。
- 文件 / 符号：`src/pages/pda-wool-fact-execution.ts`、`src/pages/pda-exec-detail.ts`、`src/pages/pda-exec.ts`、`src/pages/pda-handover.ts`。
- 修改：毛织执行只允许填报 / 横机 / 完成；辅助、特种执行只允许填报 / 完成；交接只允许接收 / 交出；显示与事件执行共用动作白名单。
- 验证证据：动作集合专项、错误动作注入契约、三类工艺执行 / 交接页面。
- 完成条件：动作互斥，保存复用既有领域入口，仓管不存在第二套事实。

### WP-2：生产单 / 加工单扫码优先

- 业务目标：三个高频动作先识别现场单据，不让操作员翻列表猜单。
- 文件 / 符号：`src/data/fcs/wool-pda-scan.ts`、`src/data/fcs/special-craft-pda-scan.ts`、`src/pages/pda-exec.ts`、`src/pages/pda-handover.ts`、`src/main.ts`。
- 修改：按加工单优先、生产单其次精确解析；处理唯一、多候选、跨厂、状态不允许和无结果；扫码枪回车与按钮共用解析。
- 验证证据：解析专项、回车交互、生产单多候选页面。
- 完成条件：三类工艺的接收、交出、填报均可扫码进入，多候选不自动选择。

### WP-3：仓管旁路完整删除

- 业务目标：仓管只管理通用库存，不能推进三类加工单。
- 文件 / 符号：`src/pages/pda-warehouse.ts`、`src/pages/pda-warehouse-wait-process.ts`、`src/pages/pda-warehouse-wait-handover.ts`、`src/data/fcs/special-craft-pda-warehouse-actions.ts`、旧专项脚本。
- 修改：删除菜单、页面、草稿、字段、处理器、写动作文件和旧专项；旧 URL 只跳正确交接子 Tab。
- 验证证据：生产源码残留扫描、删除文件检查、仓管首页和两个旧 URL 浏览器验收。
- 完成条件：不存在旧 DOM / 命令 / 处理器，旧链接无法写入加工事实。

### WP-4：待办、图片与相邻权限

- 业务目标：从待办进入正确 Tab，扫码结果可以可靠核对对象，保留其他流程权限边界。

- 完成条件：入口职责一致，图片与对象同块，其他工厂流程不回归。

### WP-5：追踪、治理与本地验收

- 业务目标：形成需求、实现和当前版本证据闭环。
- 文件 / 符号：统一总体设计、追踪矩阵、原型审查记录、专项检查脚本和 `package.json`。
- 修改：删除旧“毛织单独收口”的文档口径；建立三类统一契约；运行最终专项、构建、治理、CodeGraph 状态、任务收据和局域网验证。
- 验证证据：命令输出、浏览器截图、控制台、LAN HTTP 200 和任务收据。
- 完成条件：矩阵没有无说明的待实施项；最后一次实质修改后的证据有效，未能完成的门禁有明确原因。

## 4. 依赖顺序

1. 先锁定动作白名单和旧逻辑删除边界。
2. 再建立两类扫码解析器并接入执行 / 交接。
3. 然后修正待办、图片和旧 URL。
4. 最后做源码残留、专项、构建、治理、PDA 页面和局域网验证。

## 5. 风险与处理

- 一个生产单可能对应多张加工单：必须候选选择，禁止默认第一张。
- 相同单号可能出现在其他工厂：解析必须先限定当前工厂。
- 只隐藏按钮仍可由旧 DOM / 查询参数触发：事件层必须再次校验动作白名单。
- 删除共享仓管分支可能影响其他工厂：只删除毛织 / 辅助 / 特种工艺分支，保留通用与其他工厂逻辑。
- 隔离工作树没有 `.codegraph`：未经确认不初始化；最终如无法同步，记录为验证限制，不冒充已通过。
