# 候选工作项目录与实例化规则

这是设计目录，不是“每笔任务必须执行全部动作”的清单。是否适用依照需求、BOM、工艺、采购方式、数量批次及资料复用决定；同一种工作可按多个物料／工厂／批次产生多个实例。实际数量以任务工作树计算。T0事件、首批／90%里程碑及阶段摘要不重复算作加工工作项。

当前目录共 **77种候选动作**：S01 3、S02 13、S03 20、S04 5、S05 7、S06 7、S07 7、S08 8、S09 7。编号是本版目录的稳定引用。下表“规则”引用主方案第07节会议候选规则或分类配置，尚未发布的预算不得展示为正式标准。主例31个计时实例采用明确的Mock预算，具体到每项见mock-scenarios.md；组代理与本目录更细的执行动作是两个展开层次。

每一行都具备“结果是什么、什么时候开始、什么时候结束、谁负责”的定义。正式配置还要补起止事件字段名、唯一关联键、具体责任人和适用条件。表内团队是默认责任，实际任务必须落实到团队及人员；接收动作由接收方确认，不以运输方声明代替。

## 组代理与子动作的处理示例

主例W29“车缝及合格回货交接”代理覆盖ACT-S07-01～07，6天是从本批输入／任务满足至合格回货实收的整组演示预算；W30覆盖适用ACT-S08动作，1天是后道至可发库存的整组演示预算。默认显示组，并可展开内部动作的责任、实际事件、数量与“单项标准待配置”。质量处置只在发生时新增，不是每次默认执行。

如果要把W30从组预算改为完整叶子配置，可用一组**独立的演示细分**：已具备输入后，接收检验0.10天＋后道排队0.10＋后道执行0.35＋终检0.15＋交出0.10＋仓实收0.10＋入库0.10=1天；不合格处置不适用。这组是拟配置演示，未写入主例31项作为额外预算。正式实施需要在选定版本内用这些子项替换W30，阶段实例数相应变化，公式仍为24天。

发货订单关联与核算是必要业务／数据工作，但发生在实际发货时或其后。其记录延迟只影响数据及时性，不得将“系统第二天才算出结果”计成“第二天才发货”。归属未明时生产任务完成结论暂缓，最终完成时刻依据真实实发事实与必要的范围变更事实，不能以报表计算时刻替代。
