# PCS 测款商品绑定修正

## 已确认需求与边界
2026-09-24 用户确认：新建页与列表等宽；买手绑定商品，不允许建单填写或选择；商品信息引用系统设置 / 基础配置。保留独立建单、商品档案唯一来源及原测款步骤。
基础配置提供字典，商品档案保存选中的配置 ID；展示解析当前配置名称。现有演示商品补齐 Mock 绑定，新建未知商品不随机套值；历史用户修改保持。没有三级类目的配置显示未设三级类目。商品类型、材质类型目前没有对应配置维度，继续保存在商品档案。

## 实施计划
1. BIND-001：移除新建页最大宽度，保持列表相同 p-4 容器；两种桌面尺寸比较边界。
2. BIND-002：商品档案保存买手 ID / 名称；既有商品项目负责人作为已有买手来源、无项目演示商品显式 Mock 绑定；新建只读，列表和详情统一读取绑定。错误输入不能覆盖商品买手。
3. BIND-003：档案保存配置引用，商品信息解析品牌、三级分类和全部标签；已知演示商品补齐一次性关联；旧存储无需清空。
4. BIND-004：档案维护选项从基础配置读取；品类编号与名称由同一配置项提供；停用项不作为新增选择，已有绑定仍可识别。
5. BIND-005：专项契约、类型检查、命名页面、图片与性能；记录版本、原始样本及不适用项。

- 基础配置尚未细分的男装三级类目显示“未设三级类目”；已存在下级但档案绑定到二级的商品显示“未指定三级类目”，不把短裙错配成长裙。
