# 染色印花提前加工单测试验收数据

> 版本：2026-09-17
> 数据性质：HiGood 原型验收 Mock 数据，不代表真实生产、工厂或订单事实。
> 适用范围：生产需求单提前创建染色、印花加工单，技术包核验，单需求／多需求合并生成生产单后的自动匹配、取消与重建。

## 1. 验收口径

- 大货提前加工单来源为 `PRODUCTION_DEMAND`；设计改款制作销售展示样衣的加工单继续使用 `DESIGN_REVISION`，两类来源互不替代。
- 一个生产需求单至多归入一张生产单；多个生产需求单可以合并生成一张生产单。
- 合并生产单遍历全部来源需求单，一张生产单可以匹配多张提前染色、印花加工单；每张提前加工单仍只绑定一张生产单。
- 计划加工数量按 `生产需求数量 × 预估单件用量 × (1 + 损耗率)` 计算并保存快照。
- 染色、印花必须形成不同的投入和产出 SKU；水溶与染色同道时只创建一张染色加工单。
- 专业成果必须审核通过；印花成果中的花型图和花型文件属于同一成果，且均支持多个附件。
- 创建人必须在生产需求单下手动选择具体调色／花型任务，并明确加工厂；任务与需求不一致或加工厂为空时阻断。
- 下游接收方在正式生产单匹配成功前保持待确认，不从加工厂、生产需求或历史数据预填。
- 未完成单允许取消并重建，旧单和替代单双向留痕；已完成单不得被取消覆盖。

## 4. 边界数据

| 数据 | 预期 |
| --- | --- |
| DEM-202603-0006 专业成果未审核 | 不进入普通可创建列表；创建服务直接阻断并说明“专业成果待审核” |
| 相同需求、工艺、物料来源行、任务、成果版本重复提交 | 阻断并返回已有有效加工单，不生成重复单 |
| 投入 SKU 与产出 SKU 相同的染色或印花 | 阻断创建 |
| 已发布技术包不含对应 BOM、路线或 SKU 不一致 | 进入“匹配异常”，保留提前单且不静默补建重复正式单 |
| 合并组仅部分需求有提前单 | 已有提前单部分复用；未覆盖需求按数量占比保留正式加工快照并补生成正式加工单 |
| 同一需求单尝试归入另一张生产单 | 阻断并提示生产单归属冲突 |
| 专业任务不属于所选生产需求单 | 阻断并提示重新选择属于该需求的调色／花型任务 |
| 未选择加工厂 | 阻断并提示“创建提前加工单时必须明确加工厂” |
| 未匹配正式生产单 | 列表下游显示“待匹配生产单后确认下游”，不得提前写入接收方 |

## 5. 自动化验收映射

专项命令：

```bash
npm run check:production-demand-early-process-work-orders
```

专项测试覆盖：

1. 染色、印花各 7 条数据及全部匹配状态。
2. 印花成果多图片、多文件。
3. 数量公式、损耗率和投入／产出 SKU 校验。
4. 未审核专业成果阻断。
5. 多生产需求合并为同一生产单并匹配多张提前加工单，重复稳定键被阻断，正式匹配不回写提前计划量且事务可回滚。
6. 合并生产单仅部分需求存在提前单时的数量覆盖与正式单补建。
7. 匹配异常时禁止静默生成重复正式加工单。
8. 取消、重建及新旧单双向关系。
9. 无提前单时继续生成正式加工单。
10. 待技术包核验的提前单在技术包就绪后由同一匹配服务重试成功，并保留原计划数量与操作事实。
11. 同一需求下精确选择多个专业任务中的指定任务，并完整保存所选成果与全部附件。
12. 任务与需求不一致、加工厂为空时分别阻断；下游在匹配前保持待确认。

最终状态以本文件所列命令在当前分支最后一次实质修改后的实际输出为准；构建或历史绿灯不能替代专项测试和命名页面验收。
