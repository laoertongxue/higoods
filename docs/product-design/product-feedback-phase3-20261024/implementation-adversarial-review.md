日期：2026-10-24。依据：[已确认方案 V1.1](../商品反馈管理三期完整方案-2026-10-24.md)，D31～D40。

主代理实施与浏览器验收；一个独立只读审查代理从业务规则和产品流程提出反例，主代理修复，再由该审查者复核。未安排并行写代码或下级代理。审查对象为 `codex/product-feedback-phase3` 未提交工作区，基线 `297cdf4ffb83a4b174a37221e5aafcc7774d5c6d`。代码及构建身份另见同目录实施追踪与产品记录，不将设计阶段审查冒充实现阶段审查。

## 对抗问题与关闭结果

| 环节 | 反例 / 风险 | 修复与复核 |
| --- | --- | --- |
| 连续处理 | 保存草稿后继续使用旧队列版本；跳过提示提前清除未保存标记 | 读取最新队列版本；继续编辑保留输入。浏览器完成保存草稿、继续与回读。 |
| 草稿恢复 | 一级草稿不恢复；细分确认后旧草稿复活 | 恢复未被消费的一级草稿；正式细分消费旧草稿。模型与浏览器核对。 |
| 细分确认 | 无表现空说明、相反表现同句无语境、同步修改一级绕过修订原因 | 正式校验说明、分别依据与语境，在修改一级前固定原正式结果事实。反例均被阻断。 |
| 并发 | 旧页面覆盖新细分；保存译文吸收新修订后继续提交旧输入 | 单条与批量固定读取时细分修订；编辑器固定评论版本和细分修订。自己保存译文仅递增本次评论版本。撤回新增修订，不改写旧确认。 |
| 队列范围 | 更新队列扩大回查、待处理与具体表现范围 | 初建与更新复用同一过滤谓词，保存来源视图；明确预览新增和移出。浏览器回查4条更新后仍为原4条。 |
| 正式专题 | 正式对象保存草稿降级；草稿转正式绕过重复检查 | 正式修改不退回草稿；重复区别检查同时覆盖新建与草稿转正式。 |
| 成员及范围 | 窄范围问题冒充全款覆盖；普通编辑刷新映射基线 | 以真实元组覆盖；普通修改保留元组；显式范围变更不自动恢复旧关联声明。关联独立保存所用元组修订。 |
| 范围修正 | 范围外证据被隐藏，无法解除；修正到1款无法保留有效历史 | 表单继续展示范围外引用并明确解除；正式专题可修正到1款并标需调整，新建仍需2款，1款不能按全部结束归档。 |
| 单款关联 | 嵌套创建后写入旧专题引用 | 重新取得同一原子结果中的专题与成员；模型及浏览器完成本款问题与有效关联共同保存。 |
| 归档 | 归档后按最新问题状态冒充当时结果 | 保存范围、证据、元组、各款进度、问题、行动、计划和正式复盘快照；当时与当前分别阅读。子问题状态不改变。 |
| 经验修订 | 新版启用后残留旧草稿；旧版引用被最新内容覆盖 | 消费待启用草稿，保留版本历史、引用修订和内容快照。 |
| 经验来源 | 停用或来源变化后，从旧文字继续复制新行动 | 选入与新行动提交均核对经验ID、修订和来源；旧记录保留。模型反例阻断，浏览器正常引用与新行动保存通过。 |
| 对比来源 | 只保存经验ID，无引用事实及准确版本 | 同事务保存准确经验修订快照与唯一目标引用；提交核验选中时的依赖。 |
| 统一范围 | 共同店铺只约束评论C，未约束覆盖和未知时间存量 | 先形成有效范围，再统一计算全部相关指标；独立反例通过。 |
| 统一筛选 | 专题指标、细分候选忽略查询；引用目标按修订重复累计 | 卡片、表格、候选按对应筛选；目标按经验ID、类型、目标ID去重，引用明细保留修订。 |
| 交互 | 备注导致对比预览失效；子视图Esc无效；复选框回滚；宽表入口遮挡 | 仅统计条件废弃预览；正确转发Esc；保留原生复选框点击；固定操作列与评论详情增加细分直达。 |
| 规则阅读 | 规则抽屉缺例句、来源、业务版本与引用数 | 在规则抽屉补齐，主页面保留简洁业务提示。 |

## 独立审查结论与边界

独立审查在直接执行模型反例、阅读最终相关差异后，确认主要业务阻断均已关闭，并复核并发增量、正式专题修正到单款的增量。未操作主代理共享浏览器；视觉、保存回读、响应时间和本地数据切换另以产品审查记录中的直接证据为准。其结论不代替用户接受或真实业务验收。

静态 Mock：36条评论、13条单款问题、5个专题、4条经验，仍为两款商品，所有评论者存在。专题包含跟进、草稿、停止协调后归档、作废；经验包含有效、草稿、停用及来源重开。正常数据通过实际业务命令形成，不直接填终态。原评论没有对应买家原图素材时保留无图，不拿商品图冒充买家实拍；商品识别仍使用对应档案真实图片。

不发布、不推送、不合并main。本次是单浏览器本地Mock实现及验证，不表示真实采集接口、真实多人共享或工厂业务已经完成。
