# FCS 任务分配菲票装袋推荐实施与追踪矩阵

## 目标与边界

车缝任务及以车缝为首工序的合并任务，在直接派单、发起竞价和改派时，默认基于当前菲票装袋事实推荐完整 SKU 组合；用户也可切换为自由分配。两种方式的最小颗粒度始终是完整 SKU，不拆分同一 SKU 数量。

本次不改变裁床拆袋重装时点，不创建拆袋重装待办，不改变 PDA 的开始/交出操作，不改变合同内容，也不把装袋信息写入合同。

## 实施顺序

1. 从裁床事件账投影当前袋—菲票—生产单—任务—库位事实；无现场事件的演示生产单使用明确标识的演示快照。
2. 分别计算任务 SKU 件数、装袋裁片片数、可换算的任务覆盖差异、跨袋关系和推荐组；没有齐套换算依据时不用“片”扣减“件”。
3. 在直接派单、竞价、改派共用弹窗中展示装袋快照，并支持刷新、按组选择和自由选择。
4. 保存分配方式和快照摘要；价格仍单独二次确认。
5. 用数据契约、页面交互、构建和正反向审查闭环。

## 验收场景

- 正常：S、M 同袋且 M、L 跨袋，系统把 S/M/L 作为一个推荐组；XL 独立成组。
- 部分装袋：XL 任务 1200 件、已装 900 片，显示未装袋差异但仍可派单。
- 自由分配：只选 M 时显示会影响与 S/L 共袋的袋，不自动创建拆袋待办。
- 无装袋：显示暂无装袋记录，仍可选择完整 SKU。
- 异常混装：跨生产单袋展示异常并排除推荐，仍可继续分配。
- 已交出：不计入推荐；改派时提示由现场按最新任务处理。
- 单位不可换算：现场事件只有裁片片数时，保留片数原始事实，未覆盖任务显示“待齐套换算”。
- 非车缝任务：只显示普通完整 SKU 选择，不显示菲票分配方式，也不执行按袋校验。
