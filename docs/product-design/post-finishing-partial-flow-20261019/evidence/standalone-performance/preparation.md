| 家族 | 样本与完成条件 |
| --- | --- |
| 冷进入、刷新 | 每次冷进入采用新隔离 Chromium 上下文；刷新在同一上下文中单独采样。新文档时间原点开始，直到 D1 实际内容、必要图片、字体与交互就绪后两帧。 |

| M/L 数量输入 | 每轮包装登记的真实输入事件，核对页面值、内存表单值与本次合计显示后两帧。 |

| 超本尺码上限、模拟保存失败 | 各 5 次，通过实际输入与界面模拟结果控件触发；错误信息、原加工/复检/出货/历史不变且输入保留，恢复正常后继续同次真实保存。模拟失败不能当作主应用真实 IndexedDB 中止。 |
