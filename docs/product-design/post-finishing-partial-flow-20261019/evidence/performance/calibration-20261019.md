## 后续诊断记录

修复 R 的多余快照后，普通 QC 领取／完成单例已降至 792.5／831.5 毫秒；图片 Esc 补回既有局部处理标记后，普通关闭单例为 76.9 毫秒。15 个命名路由功能预检均通过。这些均为校准，不代替正式每家族五样本。

Storage 首轮完整 D10 普通校准为导出 1247.3、恢复 7469.6、显式版本转换 2405.5 毫秒，均保留有效失败。随后 CPU 诊断显示恢复写事务约 4.84 秒，转换写事务仅约 2.9 毫秒而有五次全量读取。删除导出多余整页刷新、按来源归组日志等局部优化后，导出普通校准 344.7 毫秒，恢复仍为 6450.5、转换仍为 1281.8 毫秒。后续修复及正式复测尚待执行。
