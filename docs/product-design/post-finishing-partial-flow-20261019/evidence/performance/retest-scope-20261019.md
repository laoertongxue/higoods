## 最终修订：全部 100 家族 / 520 新样本

主代理根据当前全局构建 CSS 与原 formal 未保留全部旧 JS 字节的边界，决定对 10 个 DOM 就绪后的 PDF 生成家族也重测 50 个实际新动作。最终不继承任何旧性能毫秒值：**100 个新家族、520 个新样本**。旧 PDF、原 1109 页和 22 页视觉检查继续保留固定字节身份，仅用于模板/当前 print-media 几何对应的视觉参考，不重称为本轮新 PDF 的完整视觉检查。

采集器正式参数恢复为全部 families、五轮、不传 `--skip-pdf`。新打印冷入口后，在同一页面核对原出货/QC/父单身份、SKU 冻结值、应交/实收、每 SKU 份数和序号、图及价格；页面图片 decode 与字体就绪纳入冷载终点。另切换真实 print media，按模板使用 A4 内容 viewport 读取 computed box、padding、条纹/图框、字体、内部分页、末张 break-after、表格边界和 QR；再恢复 screen 媒体与原 viewport 后进行本轮真实 PDF 生成，所有输出保存在新目录，不覆盖原 PDF。

固定第一生产 fixture 的价/质检材料由对应当前源声明核对（首单号限定 `PO-QC-202608-001`，264000，六种质检辅料/五个尺码）；源文件 SHA 随新打印检查记录，不将其他生产单套用该价格。文档/数量/冻结条码/图片则从该张实际 D10 持久备份读取。

本修订时只做静态编写和语法检查，没有开启浏览器。新增内容和几何 collector 必须先经实际最大打印样本校准，若出现采集假设错误，单独保留无效轮次并改版本；真实慢值仍原样保留，门槛不放宽。正式默认首个超门槛/无效采集保存后停止当前 run 并关闭浏览器，不以减少样本或继承旧值完成最终验收。
