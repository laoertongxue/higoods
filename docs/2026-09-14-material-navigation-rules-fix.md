# 导航与规则配置修复

用户要求：修复两套导航无父子关系，以及配置页参数难理解、作用范围不清的问题。

## 实现与验收

| 条目 | 实现 | 验证 |
|---|---|---|
| 导航包含关系 | 物料全景包含库存明细/健康；供需计划包含平衡与方案/备料；消耗分析包含包材/日报/商品；风险包含异常处理/预警 | 直接进入子页父级高亮；子导航仅显示所属页面；浏览器通过 |
| 总览不冒充健康页 | 恢复未来缺口分布与决策列表，健康归属物料全景 | 浏览器通过 |
| 配置用途 | 更名规则与配置，先显示规则用途和适用目录 | 浏览器通过 |
| 参数含义 | 统计口径和补充策略分组，每项带业务解释和示例 | 页面检查 |
| SKU单位 | 单位随SKU选择更新，专用策略列出基本单位 | 浏览器通过 |
| 影响边界 | 主目录43个SKU的供需规则可试算发布；其他独立规则明确管理位置与未统一发布状态 | 浏览器通过 |
| 本页规则入口 | 业务页跳转到配置目录对应规则锚点 | 浏览器通过 |
| 回归 | 原试算失效、角色限制、发布历史、备料及五业务页布局 | 共15组浏览器通过，1366×768与1280×720 |

代码不改变既有计算公式或线上数据；没有把未接入功能显示成已生效。完整产品验收仍遵循主验收记录中的未完成项。本次最终工程检查见 output/material-decision-evidence/task-receipt.json。
