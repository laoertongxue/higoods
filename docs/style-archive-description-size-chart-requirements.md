# 款式档案商品描述与尺码资料需求

依据：2026-10-09 用户明确要求与线上描述和尺码工具一致，并直接核对商品 229039 的 HTML、控件、选项和生成脚本。本次仅补齐 PCS 款式档案资料，不修改线上管理系统。

1. **DESC-001**：商品描述默认展示已有信息；已有用户保存内容（包括明确清空）优先。尚无该语言资料时使用完整线上默认模板（Regular、洗涤、季节、材质、购买说明、PILIH UKURAN 表格及客服说明）；静态参考尺寸 M/36/97/123、L/37/101/124、XL/38/105/125、2XL/39/109/126 仅为原型演示默认。静态演示档案不得默认显示空描述。
2. **DESC-002**：商品描述支持线上同类格式工具、HTML 源码、全屏、表格、链接与媒体；保留受限安全字体、颜色、对齐、尺寸样式。描述尺码表 600px 居中、黑色表头、灰白间隔行、24px 标题、14px 说明及客服说明，详情和重开同样保留格式；过滤脚本、事件属性和内嵌文件字节。
3. **SIZE-001**：独立维护工厂做货尺码表；空表保留为空，不从销售尺码自动推导生产标准。
4. **SIZE-002**：生成工具复用线上 14 个示意图选项的原始 JPG，可查看大图；包含原顺序 372 个尺码、41 个参数、瘦身类型、弹性、透明度、尺码纵向、欧码/美码/英码预留选择，展开/折叠及多选行为一致。预留选择按线上当前脚本保存选择，不自动换算。
5. **SIZE-003**：选择尺码与参数后点击“生成尺码”建立可填矩阵；无选择阻断生成。测量值由用户填写，支持数字、范围和 free；空值阻断插入。插入商品描述、工厂表及已启用 ID/MY/PH/VN 国家描述，按当前表格替换原尺码块，不叠加、不覆盖其他正文/表格。
6. **IMAGE-001**：每次插入同时生成至少 600×600 PNG 预览；“上传图片”在当前原型中绑定该 PNG 至当前档案，保存时存原始 Blob；删除图片（保存后生效）、重新上传及查看尺码表图片；默认静态参考图片随应用发布，不首次写入浏览器；图片与当前款式绑定，大图支持按钮、遮罩和 Esc 关闭，上传校验类型、大小及可读性。
7. **SAVE-001**：描述、多语言内容、工厂尺码表、测量值及图像引用随档案在原有 IndexedDB 事务中保存；普通读取不落盘演示种子，失败保留输入，识别多标签页冲突。
8. **PERF-001**：冷启动、刷新、站内切换及受影响操作在 1366×768 / 1280×720 验收，每项至少五轮，完整响应不超过 1000ms，保留失败样本。

正常场景：已有款式打开后看到默认描述，填写实测尺寸，预览，分别应用到销售描述／工厂表，生成图像，保存并刷新查看。

边界场景：未填尺寸阻断生成；写事务失败不生成半套档案／图像；重试可保存原输入；另一标签页已修改时不静默覆盖。

不在范围：线上商品修改、真实工厂尺码确认、TikTok 发布、生产技术包尺寸变更、后端接口、其他模块迁移、浏览器资料维护工具。示例尺寸只用于隔离验收，不能当作实际款式尺寸。

变更记录：本版撤销上一版八类型、八列、正数校验和简化描述口径。线上原尺码图片链接返回 404，默认参考图片由同一参考表格绘制；原始示意图已取得。上传动作仅为当前原型本地附件绑定，不调用线上上传接口。

最终格式保存补充：字体、颜色、背景色、下划线须在切换源码、保存和重开后保持；不得仅以按钮可点击或暂时显示判定通过。
