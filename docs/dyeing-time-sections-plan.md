# 染色加工单四段时间调整

用户确认版本：2026-09-14；本次范围为染色加工单时间展示及相应事实取值，不调整库存、数量、状态或其他加工厂。

## 1. 业务与取值

时间列保持原有表格位置，以与数量列相同的横线分为单据创建、上游接收、加工生产、下游交出四段。详情展示相同汇总及逐笔记录，实际发生时间只读。计划完成仍可编辑。导出与列表采用同一时间数据。

生产需求时间从关联生产单的真实需求记录获取，生产单时间从生产单创建记录获取，染色单时间保持自身创建时间；同步纠正需求单号及流转卡映射。备货单没有生产需求及生产单时明确“不适用（备货创建）”，不得拼凑时间。

调拨审核通过、上游实际创建交出分别生成待接收。送货时间与审核时间分开，实收只采用正数量接收记录；零数量记录单列“零收货登记”。备料可先收后关联加工单。

加工生产展示计划完成、染色开始、染色完成、加工完成；加工完成以包装完成记录为准，不用染色结束代替后续工序结束。交出建单、实际交出、下游实收分别读取对应记录。作废交出不计入有效发生时间。

同一事件多笔时展示首次、最近及笔数；详情保留每笔时间与关联单据。未发生显示“尚未…”，已发生而旧数据缺少时间显示“历史时间未记录”。更新时间、当前时间、数量推算均不得冒充业务事件。

正常场景：需求→生产单→染色单→审核形成待接收→送货→实收→染色→包装完成→建交出单→实际交出→下游实收，各阶段分别取值。

边界场景：先收备料后建染色单允许接收早于建单；分批接收保留各次实收；零收货不产生实收时间；草稿交出仅有建单时间；缺历史时间不以更新时间补齐。

核查补充：DWO-003、DWO-009 的原始演示日期早于所关联的六月生产单，DWO-009、DWO-010 原包装结束早于后来补齐的染色节点；仅修正这些演示场景的原始时间，保留标识、数量和状态。已有仓库出库记录的明确时间也纳入展示。
