# 后道页面交互与入口收口实施计划

> 对应设计：`docs/product-design/2026-09-03-后道页面交互与入口收口调整方案.md`

## 工作包

### WP-1 开始后道弹窗

- 业务目标：关闭与确认开始均可执行。
- 修改位置：后道加工单弹窗挂载和事件处理。
- 验证：浏览器自动化依次执行打开、关闭、重新打开、确认开始和详情状态核对。
- 完成条件：弹窗关闭且确认开始后进入唯一加工单详情。

### WP-2 打印入口收口

- 业务目标：非质检页面不展示质检打印入口。
- 修改位置：后道加工单、复检单、两个后道仓、出货单、日志、授权码页面。
- 验证：静态契约与命名页面浏览器检查。
- 完成条件：上述页面无两个质检打印按钮，质检单页面仍保留。

### WP-3 日志详情独立展示

- 业务目标：列表和详情互斥展示。
- 修改位置：差异与操作日志页面渲染分支。
- 验证：列表页存在筛选与列表；详情页只存在详情及三个详情页签。
- 完成条件：详情页无筛选、统计、列表和分页。

### WP-4 回归与交付证据

- 运行专项检查、受影响浏览器测试、构建、列表治理、原型治理和 CodeGraph 同步。
- 更新追踪矩阵与原型审查记录后再声明完成。
