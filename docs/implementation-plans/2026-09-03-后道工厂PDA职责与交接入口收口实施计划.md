# 后道工厂 PDA 职责与交接入口收口实施计划

## 1. 完成标准

以“执行只做后道、回货归交接、仓管无回货/成衣仓收货入口、自助回货可正确启停”为完成标准。最后一次修改后必须通过专项静态检查、构建/治理检查和 PDA 命名页面浏览器验收。

## 2. 工作包

### WP-01 后道工厂识别与执行页收口

- 业务目标：当前后道演示工厂与专用后道工厂使用同一职责判断。
- 文件/符号：`post-finishing-domain.ts`、`renderPdaExecPage`。
- 修改：建立后道工厂判断；后道工厂执行页仅渲染后道加工与复检入口。
- 证据：专项检查 + `/fcs/pda/exec` 双视口页面。

### WP-02 回货入口迁入交接并恢复自助模式

- 业务目标：回货责任确认统一在交接待接收。
- 文件/符号：`renderPdaHandoverPage`、`renderPostFinishingSewingSelfReturnPanel`、相关事件处理、`pda-sewing-self-return.ts`。
- 修改：增加送货单点数入口；让所有后道现场人员看见自助回货能力，管理员负责开启；补齐锁定状态写入和退出清除。
- 证据：管理员开启/退出、操作员权限提示、回货确认入口浏览器测试。

### WP-03 仓管和成衣仓收货旧入口删除

- 业务目标：后道工厂 PDA 不承担成衣仓收货。
- 文件/符号：仓管页、PDA 路由、异步渲染器、事件处理器、后道 PDA 流程页面、出货打印。
- 修改：删除仓管快捷组；删除后道出货收货页面及可达事件；打印保留业务条码但取消旧 PDA 扫码目标。
- 证据：正向入口缺失检查、反向旧字符串扫描、旧地址不可达测试。

### WP-04 契约、页面和治理验证

- 修改：同步现有专项脚本和跨端测试的业务边界；新增本次 PDA 职责专项验收；记录原型审查。
- 证据：专项脚本、Playwright、构建、原型治理、CodeGraph 状态和任务收据。

## 3. 实施顺序

`WP-01 → WP-02 → WP-03 → WP-04`。其中 WP-03 只删除后道工厂 PDA 的成衣仓收货表现，不删除后道出货单及其下游业务事实模型。
