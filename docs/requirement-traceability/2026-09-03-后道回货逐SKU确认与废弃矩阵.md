## 正向追踪

- 两种来源与逐 SKU 明细：`RETURN-SKU-*` → WP1/WP2/WP4 → 共享回货行、Web 详情、自助回货记录。
- 点数、5%与自动质检：`RETURN-CFM-*`、`RETURN-AUTH-*`、`RETURN-QC-*` → WP1/WP3 → 领域确认动作与专用 PDA。
- 废弃闭环：`RETURN-VOID-*` → WP1/WP2/WP3/WP4 → 状态、库存投影、日志及三端入口。
- 旧入口收口：`RETURN-LEGACY-*` → WP5 → 后道特殊渲染和事件处理防御。
- 图片、兼容和交付：`RETURN-IMG-*`、`RETURN-COMPAT-*`、`RETURN-GOV-*` → WP2-WP7。

## 反向追踪

- 共享数据新增字段和动作只服务 `RETURN-VOID-*`，没有引入恢复、补料或后端能力。
- Web 仓库改动只服务 `RETURN-SKU-002`、`RETURN-VOID-*`，没有重排统计卡、页签和标准列表主体。
- 专用 PDA 改动只服务 `RETURN-CFM-*`、`RETURN-AUTH-*`、`RETURN-QC-001`、`RETURN-VOID-001`。
- 自助回货改动只服务 `RETURN-SKU-001/003`、`RETURN-VOID-001/002`。
- 旧交接详情的分支只服务 `RETURN-LEGACY-*`，其他交接类型仍沿用旧行为。
