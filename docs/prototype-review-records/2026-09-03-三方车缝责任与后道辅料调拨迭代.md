| 项目 | 内容 |
| --- | --- |
| 记录日期 | 2026-09-03 |
| 相关需求 / 任务 | 三方车缝任务责任、质检分流、后道辅料调拨、Web/PDA 联动 |
| 记录模式 | 完整产品审查 |
| 涉及系统 | FCS / PFOS |

## 2. 影响判定

- 用户可见影响：有
- 判定依据：在既有后道生产任务、质检、加工、复检、仓库、出货、日志和 PDA 页面骨架上增加任务责任、质检去向和辅料到位提示；新增“后道辅料调拨单”标准列表及右侧详情抽屉；在“后道待加工仓”原页签末尾增加独立辅料库存；在 PDA 交接“待接收”内增加辅料整单入库。未迁移框架，未推翻待加工仓/待交出仓原四卡、原成衣库存、筛选、表格和分页，未新增辅料仓创建/审核/拣货或车缝配料页面。
- 审查基线：`AGENTS.md` 第 4、5、7 节。

## 3. 自查结论

| 检查项 | 结论 | 说明 |
| --- | --- | --- |
| 角色、任务与页面模式 | 通过 | Web 保持管理列表/详情模式；PDA 保持扫码与单一主动作；QC 仍只在 Web。 |
| 文案、状态、数量与单位 | 通过 | 三类任务范围、两类质检去向、调拨四状态、实配数量及 PCS 单位均直接展示。 |
| 扫码、真实图片与对象识别 | 通过 | PDA 只接受完整调拨单号；逐物料显示真实图片、编码、SPU、规格和实配数量。 |
| 防错、危险确认与主管兜底 | 通过 | 仅车缝项目锁定；调拨整单入库二次确认；无数量编辑、差异授权、补料或分批入口。 |
| 交接、跨端事实与异常追溯 | 通过 | PDA 整单入库后 Web 调拨状态和待加工仓辅料库存同步；操作日志记录责任、分支和调拨动作。 |
| 低分辨率、PDA、弱网与上传恢复 | 通过 | Web 1280×720/1366×768 与 PDA 390×844/480×800 无主体横向溢出；本次未新增上传或离线基础设施。 |
| 命名路由、交互、图片大图与打印 | 通过 | 新路由可达、列表/详情分离；沿用现有图片大图与失败态；打印兼容“后道加工单不适用”。 |
