# 本轮浏览器文案与性能验收方法

验收工作树为 `/Users/laoer/.codex/worktrees/d29f/higoods`，分支 `codex/dds-task-business-review`，基线 `86593df8502d751362cdbab8676510bc233ef0b9`。已有 Vite preview 4179 的进程工作目录已核实为本工作树。最终证据均读取 `/assets/index-DyHIx5_W.js`；页面上的 2026-10-07 09:00 是固定的 Mock 业务查看时点，实际验证于 2026-10-08 至 09 完成。

## 页面与交互

使用已授权 localhost:4179 的 Codex 内置浏览器和 `cua_repl`，没有改用浏览器、地址或间接调用绕过其他来源的拒绝设置。通过实际页面的按钮、链接和筛选字段操作；确定路径来自场景清单和已登记单据，不猜测路由。所有业务表单只打开、核对及关闭，本轮不保存跟进或写入业务资料。

冷打开在当前验收标签临时禁用 HTTP 缓存，直接导航到清单中页面；刷新使用该标签的 `reload()`。未清空网站存储、数据库或已有资料。页面自身计时从 navigation/event start 开始，等到来源读取、计算、字符串渲染、可见图片完成及两个 requestAnimationFrame 才记录 ready。读取完整 DOM 的业务文字、构建入口、计时与可见图片状态，保存逐次原始样本。`browser-measurement-code.js` 保存本轮 REPL 中的实际读取与动作封装；它需要同一授权浏览器的绑定对象及场景清单。

`browser-pages.json` 为最终 890 个样本，包含20场景、8入口、37种原模块单据代表，各冷/刷5次；另外8条代表路由在1366×768、1280×720及1024×768各冷/刷5次。每个样本均保存 overflow 和 brokenImages，均无页面整体横向溢出及可见破图。原设计中的可滚动图示不是文档整体溢出。

`browser-interactions.json` 为最终31类动作×5，共155个样本，涉及三阶段及全部阶段展开/收起、4类单据弹窗/关闭、合同晚达标节点、跟进清单、数量明细、跟进表单、查询、资料缺失筛选及更多筛选。125个动作同时记录完整 DOM/图片/溢出；30个单据打开/输入选择样本保存动作计时和构建标识，通过其后 AX 页面状态确认结果，不能声称这30个样本另行测量了 overflow。

## 导出、新标签及打印

7个有导出入口的页面，各实际点击并等 CSV 下载完成5次，共35个样本。`browser-exports.json` 同时保留页面导出就绪和点击至文件下载完成用时，后者包含浏览器工具响应耗时，是更保守的完整结果。文件列名、范围和记录内容实际核对，首份导出保存在 exports 子目录。只读口径页没有导出入口，不人为增加。

生产准备单、物料采购单、未完成绣花加工单从本页摘要点击“查看详情（新标签页）”各5次，共15个样本。仅在验收标签临时注册 click 事件 epoch，随后读取真正新标签的 navigation timeOrigin 和 ready 用时，以“新标签timeOrigin＋就绪时长－父页实际click epoch”计算全程。每组之后移除临时监听、关闭临时详情标签，未改持久状态。

打印使用浏览器 print media 和 `Page.printToPDF`，在图示就绪后计实际 PDF 生成5次，原始结果保留为 browser-print.json；首份 actual PDF 保存为 clarified-overview-print.pdf。此项证明浏览器打印引擎输出，不证明外接打印机物理出纸。PDF为两页，使用现有 pdftoppm 渲染两页PNG，主代理分别视觉核查；未冒充通过不可用的PDF文字提取工具。打印后恢复 print media，验收结束恢复缓存设置与临时viewport。

## 原始样本和诊断边界

所有有效最终样本逐次保留，不按均值掩盖慢样本；每组至少5次，每次不超过1000ms。汇总及对应最大值见 acceptance-summary.json。当前控制台 error 检查为0，保存于 console-errors.json。

此前构建版本的 browser-pages-pre-final.json、browser-pages-before-last-copy.json 和 browser-interactions-pre-final.json 只作历史过程，不能当最终版本证据。过程中曾修正测量函数捕获旧资源哈希、依据真实DOM修正单据/跟进选择器、等待新标签注册，以及构建中的一次短暂资产导航失败；这些是验收脚本/构建窗口诊断，不将其冒充有效样本。发现跟进文案漏写接收、详情缺标准红色误判后实际修改了源码，并以551测试通过的最终构建重放了所有受影响页面和动作。未删除有效的超时性能样本，最终不存在超过1000ms的有效样本。

原V7同宽像素比对及实际存储故障注入是独立门禁，本轮不修改其阻塞状态，不用本轮浏览器样本替代原验收。
