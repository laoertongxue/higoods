## 2. 影响判定

- 用户可见影响：有
- 判定依据：任务分配弹窗新增当前袋装概览、袋和菲票明细、装袋推荐组、自由选择袋影响、刷新结果和价格二次确认摘要；统一任务分配页新增自动分配配置、执行预览、价格二次确认与批量结果反馈，并补齐款式、阶段、工序工艺、跟单、价格、工厂、合同等列表事实和高频/高级筛选。清理旧固定“2 个菲票袋”文案。演示生产单新增明确标识为“演示快照”的袋装数据，现场事件存在时优先读取事件账。

当前审查依据 `AGENTS.md` 第 4、5、7 节。

## 5. 主要问题与处理

| 问题 | 标签 | 影响角色 | 处理方式 | 是否仍有风险 |
| --- | --- | --- | --- | --- |
| 旧弹窗只有分配方式，没有具体袋装事实 | `读不懂` | PPIC / 生产计划员 | 增加概览、袋明细和推荐组 | 否 |
| 任务件数与菲票裁片片数可能被错误相减 | `算不准` | PPIC / 生产计划员 | 分离单位；无成套换算事实时显示“待齐套换算” | 否 |
| 自由选择看不到对现有袋的影响 | `选不对` | PPIC / 生产计划员 | 实时显示保持整袋与受影响袋 | 否 |
| 非车缝任务可能误用车缝菲票规则 | `范围错了` | PPIC / 生产计划员 | 非车缝任务仅保留普通完整 SKU 选择，不显示、不校验、不记录菲票分配方式 | 否 |
| 自动分配缺少配置和执行入口 | `做不了` | 生产计划员 | 增加工序工艺配置、候选预览、价格二次确认和批量执行反馈 | 否 |
| 自动分配可能错误纳入车缝、合并或准备加工单 | `范围错了` | 生产计划员 | 只纳入待分配的非车缝独立生产任务，并显示排除数量 | 否 |
| 原列表缺少款式、阶段、跟单、标准价与派单价对比等决策信息 | `读不懂` | 生产计划员 | 补齐业务合并列，并用“阶段”替代错误“工艺组”表达 | 否 |
| 仅靠关键词无法定位待分配、特定工厂、价格异常、合同或装袋风险任务 | `选不对` | 生产计划员 | 增加高频与更多筛选、级联清空、条件标签、单项清除和全部重置 | 否 |
| 线上旧口径可能把准备阶段、质检复检或连续工序带回列表 | `范围错了` | 生产计划员 | 列表数据继续受生产执行任务门禁约束，阶段筛选仅生产/后道，合并筛选仅两种固定范围 | 否 |
