## 2. 影响判定

- 用户可见影响：有
- 判定依据：任务分配工作台的列表字段、筛选条件、车缝分配弹窗、合同快捷入口、图片失败态和用户操作路径发生变化。

### 用户可见影响

- 任务列表收敛为任务对象、任务内容、数量、跟单责任、分配信息、价格、操作七列。
- 删除阶段、生产准备、准备风险/装袋标签、最小分配颗粒度和合同状态等列表表达。
- 默认筛选只保留综合搜索、分配进度、分配方式、工序、承接工厂和派单日期；更多筛选只保留跟单、价格状态及选择具体工序后才出现的工艺。
- “更多筛选”和“重置筛选”紧接派单日期结束字段排列在同一筛选网格行，不再单独占用下一行并分散两端。
- 删除接单状态、自动分配结果、合并模式、数量区间、SKU 数区间、任务截止、币种和计价单位等低频筛选及其状态与过滤逻辑。
- 任务内容按业务工序去重，同一工序的多条工艺明细不会再拼成“特殊工艺 + 特殊工艺”。
- 独立车缝和“车缝+烫包”的直接派单、竞价、改派弹窗展示车缝辅料配料及库存、裁片齐套/放行/目标和菲票装袋事实；其他任务不展示。
- 删除准备风险知悉勾选和阻断，只保留完整 SKU、工厂、价格、截止时间、状态变化等必要门禁。
- 任务行只保留一个“合同”入口，统一查看/打印和上传签订扫描图；生产合同管理仍为独立页面。
- 新增任务日志入口，详情不再承载车缝准备信息。

| 图片与对象识别 | 通过 | 款式真实缩略图与 SPU、款式名、生产单、任务号同列；高清图支持遮罩、按钮和 Esc 关闭。 |

| 准备事实边界 | 通过 | 只在独立车缝和车缝+烫包分配动作展示；非车缝和裁剪+车缝+烫包不展示；风险不阻断。 |
| 合同闭环 | 通过 | 分配后自动生成并询问打印；单一合同入口可查看/打印或上传扫描图；失败不回滚分配。 |
| 自动分配边界 | 通过 | 只处理启用配置的非车缝独立生产任务；自动分配配置与执行保留顶部动作，不再占用列表筛选。 |
| 路由与低分辨率 | 通过 | 当前分支 1366×768 页面可操作；生产合同管理独立菜单与路由保留。 |

## 4. 主要问题与处理

| 原问题 | 处理结果 |
| --- | --- |
| 列表把阶段、生产准备和合同状态当成任务决策字段 | 删除旧列并重组为七个业务列 |
| 准备风险、菲票装袋在列表形成标签和筛选 | 全部退出列表和筛选，只在指定车缝分配弹窗提示 |
| 任务对象、分配方式、状态和工厂被拆散 | 分别合并为“任务对象”和“分配信息” |
| 数量列解释内部最小颗粒度 | 只展示 SKU 数和总件数 |
| 合同操作拆成查看/打印与上传两个入口 | 合并为单一“合同”弹窗入口 |
| 车缝准备风险需要勾选才能提交 | 删除勾选及校验；准备数据只提示不阻断 |
| 详情被错误用作“准备情况”入口 | 详情恢复为通用任务详情，日志独立可查 |
| 高级筛选混入自动资格、配置、接单、合并、数量、截止和价格单位等低频条件 | 删除非任务定位条件，只保留跟单、价格状态和按工序出现的工艺 |
| 默认与更多筛选仍堆叠大量低频条件 | 默认只保留六类常用筛选，更多筛选只保留跟单、价格状态和按工序出现的工艺 |
| 更多筛选与重置筛选单独占据下一行且分散两端 | 两个操作紧接派单日期结束字段，统一在同一筛选网格行内排列 |
| 同一特殊工艺任务的明细行重复拼接工序名 | 工序名称先按业务名称去重，工艺继续单独展示 |

## 5. 第一轮实现验证

### 自动化

- `npm run check:fcs-dispatch-list-filters`：通过，确认七列、精简筛选、工序去重、删除边界和车缝提示边界。
- `npm run check:fcs-dispatch-bagging`：通过，确认推荐组、自由选择、异常袋、已交出袋、无装袋记录和完整 SKU。
- `npm run check:fcs-auto-dispatch`：通过，确认自动配置与执行范围不变。
- `npm run check:fcs-unified-assignment-foundation`：通过，确认统一分配、固定合并、合同、回货及数据边界。
- `npm run build`：通过。

### 页面验证

- 1366×768 七列表头实际结果：`任务对象 / 任务内容 / 数量 / 跟单责任 / 分配信息 / 价格 / 操作`。
- 默认筛选不存在阶段、车缝准备风险、菲票装袋情况和合同状态。
- 更多筛选在未选工序时只包含国内跟单、印尼跟单和价格状态；选择具体工序后才增加工艺。
- 任务内容对相同业务工序去重，特殊工艺多明细只显示一次“工序：特殊工艺”。
- 独立车缝直接派单：辅料、裁片、菲票装袋与两种分配方式可见；无风险知悉勾选。
- 非车缝直接派单：车缝准备和装袋信息均不存在。
- 价格提交：二次确认文案完整；分配成功后合同生成、打印询问、单一合同按钮、上传扫描图入口均可用。
- 通用详情不泄漏准备信息；任务日志弹窗可打开。
- 图片高清预览可打开并使用 Esc 关闭。
