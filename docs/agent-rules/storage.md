# 存储操作与验收细节

适用边界、原子保存、定向重建及维护限制统一按根 `AGENTS.md` STORE-01～STORE-05、MOCK-01、EXCEPTION-01；本节只补充操作细节。

## 对象与读取

- 登记对象、静态源 / 对象仓库、读写入口、关联动作和旧项，只覆盖本次动作实际读取、修改、生成的记录 / 附件及直接读取入口。
- 偏好登记键名、大小上限和默认值，失败回默认；未保存表单 / 文件留内存并提示离开风险，不承诺刷新恢复。不得借 sessionStorage、Cache Storage 或其他键存业务快照；普通 HTTP 静态缓存可用。容量估算及 `persist()` 不保证无限容量或防用户清除。
- 静态记录按记录存覆盖值，删除存标记，明确静态版本与覆盖规则；重建范围外，发布不得覆盖修改或复活删除项。读取失败不能当空数据落种子；IndexedDB 不可用时可明确展示静态 Mock，并提示用户数据不可读 / 保存。

## 事务与附件

- 事务前计算须与事务内当前事实一致，事务中不等待无关网络 / 文件处理。事务内比较并更新版本；稳定操作 ID 用于去重，冲突提示重新读取。跨库优先统一必要归属，仍不能原子保存则报告阻塞与方案。
- 文件先校验类型 / 大小并预览，临时 object URL 及时释放，不作持久地址；JSON 仅存文件 ID、名称、类型、大小等元数据。不按名称去重，明确复制、替换和历史版本引用归属。
- 预存文件标记未关联，定义取消 / 失败 / 回收时机；引用提交前不算业务保存成功。回收同时处理引用、元数据和实体。

## 重建与指定迁移

清理范围包含相关静态 Mock、浏览器演示记录、覆盖值、删除标记和专属附件；共用库按记录处理。切换不藏在查询 / getter 中，不新增业务维护入口或通用迁移引擎。用户指定保留的迁移须分批记录进度，验证续跑、冲突、升级阻塞及完整回读后退出旧源；失败保留源数据。其余重建要求直接执行根 STORE-04，不另做旧演示数据兼容。

## 仅核对本次存储改动的缺项

已有有效证据先复用；以下场景按实际影响选择，不适用可合并说明：

- 偏好满额 / 禁用 / 抛错后默认可用；首次无整批种子副本。
- 刷新、关闭重开、下游直达后记录与附件一致。
- IndexedDB 打开失败、超限或事务中止，无未捕获异常、假成功、半套数据，输入可恢复。
- 版本冲突、重复提交、升级阻塞可识别 / 恢复；复制不重复附件字节，无引用可回收，有引用不误删。
- 重建保留无关记录和共用附件，完成标记及重试不重置新数据；指定迁移不重不丢、旧源退出。
- 源码与浏览器读写共同确认无业务 Base64、整模块重写和 localStorage 保存后备。

仅已有 / 本次确需备份恢复能力时，备份包含业务记录、覆盖 / 删除标记、Blob 和格式版本；恢复先验结构、版本、引用、重复及冲突，错误不损原数据，并验证完整回读。大数据分批，单业务动作原子，不无限增殖缓存 / 副本；无该能力不承诺清空可恢复。
