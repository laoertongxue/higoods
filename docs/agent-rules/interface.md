# 页面操作与列表细节

权限、防错、设备尺寸、组件复用和图片底线执行根 `AGENTS.md` UI-01、UI-02、LIST-01、IMAGE-01；本节仅补充设计及操作细节。

## 操作设计

依据已确认的岗位任务、语言、培训和设备设计，不按国籍推断能力。管理页展示统计追溯，执行页突出当前任务和一个主动作，优先待办 / 扫码，减少阅读、计算和手填；扫码立即显示对象与结果，复杂动作按需分步。仓储突出物位和收发差异，交接说明双方、对象、应交 / 实交、差异及责任；异常记录人、时间、原因、数量、必要图片和后续负责人。各端读取同一事实，只提供已实现的兜底、上报和恢复入口，不虚构待办、SLA 或离线能力。

复用字号 / 间距 / 控件尺寸，控件有可理解名称，业务结构用清晰的 `renderXxx()`；输入局部更新或 debounce，图标只扫描新区域。按实际规模分页 / 分批 / 懒渲染，必要时才虚拟化，不加复杂动画。红色错误 / 阻断、黄色待办 / 风险、绿色完成 / 一致、蓝色主动作 / 信息，实物颜色不受限，图标不替代关键文字。

## 标准管理列表

**LIST-01：复用标准列表，按业务提供功能。** 适用于管理 / 现场主管任务的桌面数据列表；不适用于 PDA、员工队列、固定摘要、步骤和扫码结果，字典见 EXCEPTION-02。

- 新增列表或改变结构 / 行为时声明 `// @page-pattern: list`，复用 `renderStandardListPage`、`renderStandardListTable`，分页用 `renderTablePagination`；固定少量结果不分页须写 `// @list-pagination: none — <原因>`，保留骨架和表格。历史非结构文案 / 静态外观修正可保留旧结构，但须保守结构比较、当前轻量审查及前后 SHA256 / 页面证据；涉及事件、数量、单位、地址、动态表达式或结构变化不适用，不能证明时不得用声明绕过。
- 布局参照染色加工单 `/fcs/craft/dyeing/work-orders`：标题与主操作 → 查询卡片 → 适用统计卡片 → 独立列表卡片（表头、表格、分页）。对齐边距、间距和操作区；只调整新增页及本次受影响区域，不照搬字段、指标、专用动作或无业务依据的工厂 Tab，生产准备列表不设工厂 Tab。
- 查询、统计、导出、列设置和分页按任务、规模与既有约定提供。查询条件同一卡片，高频在前，更多条件在卡内展开，查询 / 重置 / 有需求的导出集中操作区。查询同步列表、统计和总数；重置恢复约定完整结果；状态快捷筛选同步条件；无结果有反馈，不放无行为按钮。
- 导出全部筛选结果，不限当前页、不含操作列。列表标题 / 数量在左，适用批量操作 / 列设置在右，表格与分页同卡。
- `/fcs/craft/cutting/supplement-management` 用于公共能力与功能核验；不足时扩展 `src/components/ui/`，不得复制整套页面模板。
- 摘要常用 48px 单行，但不得截断关键结果，长标签、翻译和低分辨率按需换行。大量业务记录使用分页，显示当前页、每页数量和总数；少量固定字典可不分页。
- 需要列管理的宽表支持列显示、顺序、排序和冻结；冻结普通列固定左侧，必需 / 防错列不可隐藏，操作列固定右侧。列显示、顺序、冻结和每页数量按路由持久化，当前页和排序不持久化。
- 页面主体不得横向溢出，宽表在容器内滚动，设备按 UI-01。
- `scripts/standard-list-page-baseline.json` 仅登记原有历史页面身份和原始哈希，不新增或修改哈希绕过门禁；局部修正不重写基线，迁移后可删对应项。例外绑定实际版本及证据，不形成永久豁免。

## 图片与文案

识别图可用对象对应的实拍、效果或正式物料图。缩略图与名称 / 编号同块，可查看原始 / 高清图，支持关闭、遮罩和 Esc；保持比例、小屏不溢出，提供替代说明及加载 / 失败状态。已有明确上下文的确认框、日志、统计或引用按需展示，不重复堆图或删除已确认图片。

默认中文，用户要求时使用印尼语 / 双语；沿用已核读的[华为《界面用语》](https://developer.huawei.com/consumer/cn/doc/doccenter-ux-design/design-ui-language-0000001795698453)及项目约定，仅作用于本次修改：

- 结论和条件在前，一句一个重点；对象、状态、动作同名，用熟悉业务词和具体动作按钮。删重复说明，保留数量 / 单位 / 口径、差异、未保存、冲突及不可逆后果；不责备或堆礼貌。
- 异常如实写结果、已知原因及可执行办法，不编造网络原因或未实现恢复能力；成功只写已完成事实，帮助按需展开。
- 显示业务名称、正式单号、颜色 / 尺码，不露技术状态码、内部复合键或调试信息，不截断关键内容；显示名不改变扫码、持久化身份或追溯。
- 数量与单位分开，百分比 / 货币保留“20%”“¥100”，不改原值和编号。标题 / 按钮 / 状态 / Toast 末尾不加句号，完整步骤正常断句，范围用“～”。
