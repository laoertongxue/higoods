# HiGood 原型变更治理记录模板

依据 `AGENTS.md` 的 SCOPE-02、REVIEW-01、PERF-01、EVIDENCE-01；复制到 `docs/prototype-review-records/YYYY-MM-DD-<topic>.md`。本模板只记录本次实际结果，不新增产品规则。

选择一个记录模式；实际值全部填写，未执行项不得写通过。适用范围来自 REVIEW-01，包括会改变用户可观察结果的运行代码，不以页面目录决定是否记录。仅文档或治理工具且无产品运行影响时，无需复制。

| 模式 | 适用情况 | 必填内容 |
| --- | --- | --- |
| 完整产品审查 | 行为、业务或共享可见结果变化 | 基本信息、影响判定、自查、最终结论、文件、页面证据、性能、命令、例外 |
| 轻量可见变更 | 文案或样式变化，动作、数据、路由契约不变 | 基本信息、影响判定及契约变化、轻量变更、文件、页面证据、性能、命令 |
| 无用户可见影响声明 | 渲染、业务、路由及交互结果不变 | 基本信息、影响判定、文件、技术证据、命令 |

只保留所选模式要求的块。实际字段及自查表使用普通 Markdown 内容，不缩进成代码块；代码示例不能作为声明或证据。已有需求矩阵可在自查表按需求编号链接证据，不重复建大表。检查器验证结构、覆盖和声明一致性；实际页面、证据真实性、适用性和性能原始数据仍由审查人核对。历史记录可以只读追溯；用于本次交付时必须满足当前模式要求，不能省略模式退回历史标准。
