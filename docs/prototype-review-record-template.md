## 2. 影响判定

- 用户可见影响：有 / 无
- 判定依据：说明哪些页面结构、文案、字段、状态、数量、图片、Mock 数据、路由、交互和防错发生变化；或说明为何这些结果完全不变。

- `AGENTS.md` 第 4 节：印尼工厂现场产品设计基线。
