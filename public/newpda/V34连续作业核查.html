目标与 Web 现状的明确差异

1. 用户已指定辅助/特种/辅料四动作：接收仅在接收页；执行中加工填报；存在已报产且可交数量才显示发起交出；有实际交出才显示完工，完工后只读。本稿继续该规则。当前 Web 盘扣要求全部投入齐及产出交齐后完成；花边完成加工后仍可交出、可撤销完成；普通特殊工艺 Web 仅已有填报即可完工。这些是明确差异，不冒称 Web 已统一。

2. Web 中角色权限、超计划、提前结束、异常处理、数量不符/原因及二次说明均不照搬回 PDA，遵循用户已删除的范围。合法数量、当前实物、单位、来源有效性、重复提交和下游独立实收仍保留。水溶短收待处置不能直接完工，本稿不新增差异处置按钮。

3. 盘扣与花朵在当前 Web 字典仍为辅助工艺，本稿按用户要求放辅料厂。辅料厂四类保持盘扣、花朵、织带、花边；织带下保留半成品/截断/打头。

4. Web 印花填报输入是累计完成，本稿输入“本次新增合格产出”，系统累计；处理同一真实数量，不重复计数。打印/转印仍明确填累计工序完成量。

5. Web 交出单先选卷建单再逐卷核对，本稿在同一交出页选卷/扫码/运输并提交，保留实际交出与下游实收责任，不增加保存草稿的中间确认。

6. 本稿所有来料、图片绑定、加工单、司机和交接记录均为独立示例；Web 代码核查不等于浏览器读取真实业务数据。盘扣/原料原有缺图边界未在本轮伪造补齐。新增水溶图片来自正式 Web 静态素材。未改数据库、Web 或仓库代码。
